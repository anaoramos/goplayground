# Go Playground

This repository is a personal space for me to experiment with and learn more about the Go programming language.

## About
This repository contains various Go programs and exercises that I use to explore different features of the language. The goal is to improve my understanding of Go by writing small, practical examples and testing different concepts.

## Getting Started
To run the examples in this repository, ensure you have Go installed on your machine. You can check your installation by running:

```sh
$ go version
```

If you haven't installed Go yet, follow the official [Go installation guide](https://go.dev/doc/install).

## Running Code
To execute a Go file, navigate to the directory containing the file and run:

```sh
$ go run filename.go
```

For example:

```sh
$ go run main.go
```
